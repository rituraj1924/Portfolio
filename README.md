# ✨ Rituraj Thakur — Modern 3D Developer & Designer Portfolio

A modern, high-performance developer & designer portfolio website built with clean semantic HTML5, pure CSS3 (3D transforms, glassmorphism, fluid animations), and vanilla JavaScript.

🌐 **Live Website**: [https://rituraj1924.github.io/Portfolio/](https://rituraj1924.github.io/Portfolio/)

---

## 🚀 Features

- 🔮 **3D Geometric Transforms**: Rotating 3D wireframe cube and pyramid built with pure CSS `preserve-3d` and keyframe animations.
- 🌌 **Constellation Particle Physics**: Interactive canvas background particle system with dynamic distance-based connective filaments.
- 🎴 **3D Mouse Tilt Cards**: Interactive 3D perspective mouse tracking on featured project showcases and profile cards.
- ⌨️ **Dynamic Typing Role Hero**: Cycling role descriptions powered by Typed.js (`Web Developer`, `Graphic Designer`, `Web Designer`, `Video Editor`).
- ⏳ **Glowing Career Timeline**: Vertical experience timeline with pulsing glowing nodes and neon gradients.
- 🪟 **Glassmorphism Design**: Modern dark theme (`#0a0a1a`) featuring blurred frosted glass cards (`backdrop-filter: blur(12px)`).
- 📄 **Integrated PDF Resume**: Direct one-click download of Rituraj Thakur's latest resume from both the hero and footer.
- 📱 **100% Responsive**: Fully fluid layout engineered with CSS Grid and Flexbox across mobile, tablet, laptop, and ultra-wide displays.

## 🛠️ Tech Stack

- **Markup**: Semantic HTML5 with accessibility attributes and SEO meta tags
- **Styling**: Vanilla CSS3 (Custom Variables, CSS Grid, Flexbox, 3D Transforms, Glassmorphism)
- **Typography**: Google Fonts (*Space Grotesk* & *Inter*)
- **Scripting**: Vanilla JavaScript (ES6+, Canvas API, IntersectionObserver API)
- **Libraries**: [Typed.js](https://github.com/mattboldt/typed.js/) (dynamic text typing)

## ⚙️ How to Deploy on GitHub Pages

1. Go to your repository on GitHub: `https://github.com/rituraj1924/Portfolio`
2. Click **Settings** (tab at top).
3. In the left sidebar, click **Pages**.
4. Under **Build and deployment > Source**, select **Deploy from a branch**.
5. Under **Branch**, choose `main` and folder `/(root)`.
6. Click **Save**.
7. In a minute, your portfolio will be live at:
   👉 **`https://rituraj1924.github.io/Portfolio/`**
